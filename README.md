# Mikesplore

Mikesplore is Michael Odhiambo's database-driven portfolio and Telegram assistant.
The web portfolio presents his projects, writing, skills, experience, events, and
certifications. The Telegram bot, [@mikesplorebot](https://t.me/mikesplorebot), answers
questions from the portfolio and provides an admin interface for managing its content.

Built with React, FastAPI, PostgreSQL, Telegram, Groq, and Cloudflare R2.
