# Mikesplore

Mikesplore is my database-driven portfolio and Telegram assistant.
The web portfolio presents my stuff. The Telegram bot, [@mikesplorebot](https://t.me/mikesplorebot), answers
questions from the portfolio and provides an admin interface for managing its content. I can basically edit my portfolio stuff at the comfort of my seat and Telegram

Built with React, FastAPI, PostgreSQL, Telegram, Groq, and Cloudflare R2.
